# NexusCinema
      NexusCinema turns your desktop into an interactive cinematic scene. Animated themes render behind your windows, reacting to cursor movement and system activity, shifting with the time of day. Modular architecture: frames, scripts, persistent state. Lightweight, extensible, open source.

## Ce que c'est

NexusCinema est un **moteur de thèmes d'arrière-plan interactifs** pour bureau PC.
Il affiche des scènes animées derrière vos fenêtres et les fait réagir à ce qui
se passe sur votre machine : mouvement de la souris, activité CPU, heure de la
journée, luminosité ambiante.

Ce n'est pas un simple fond d'écran animé. C'est une **couche graphique
persistante** avec état, scripts et données — pensé pour être étendu.

---

## ✨ Principes

| Principe | Détail |
|----------|--------|
| **Local d'abord** | Aucun appel réseau. Aucun compte. Aucune télémétrie. |
| **Modulaire** | Chaque thème est autonome : ses frames, ses scripts, son état. |
| **Léger** | Boucle de rendu optimisée, mise en pause automatique quand une fenêtre plein écran est active. |
| **Extensible** | Ajouter un thème = ajouter un dossier. Pas de recompilation. |
